# Dripstone Caves

`minecraft:dripstone_caves` · Y **-150 to -1000** · patches about 300 blocks across · about **3.4%** of the world

Minecraft's dripstone caves biome, with layered dripstone walls added.

## Blocks
| Where | Block |
|---|---|
| Walls | Repeating 4-block bands: dripstone block, dripstone block, stone, dripstone block, tuff |
| Floor (1 block deep) | Dripstone block |
| Ceiling | Dripstone block |

## Decorations
| Decoration | On | Chance per block |
|---|---|---|
| Pointed dripstone (pointing up) | Floor | 5% |
| Pointed dripstone (hanging down) | Ceiling | 7% |

Minecraft's own dripstone features also generate: large dripstones, dripstone clusters and pointed dripstone, plus geodes, dungeons and springs. **Minecraft's ore generation is removed:** ores come only from the normal [ore system](../ores.md).

!!! warning
    Falling onto upward pointed dripstone does extra damage, and hanging dripstone can fall on you.

## Mobs
Minecraft's own dripstone caves list:

| Mob | Weight |
|---|---|
| Spider, Skeleton, Creeper, Slime | 100 each |
| Zombie, Drowned | 95 each |
| Enderman | 10 |
| Zombie Villager, Witch | 5 each |
| Glow Squid (passive, in water) | 10 |
| Bat (passive) | 10 |

Hostile mobs get a [level](../../mobs/levels.md) and can be [swapped for tougher mobs](../../mobs/spawn-mix.md).
