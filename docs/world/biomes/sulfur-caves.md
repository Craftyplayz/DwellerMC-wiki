# Sulfur Caves

`minecraft:sulfur_caves` · Y **-700 to -1600** · patches about 280 blocks across · about **3.7%** of the world

Minecraft's sulfur caves biome, with layered sulfur and tuff walls added.

## Blocks
| Where | Block |
|---|---|
| Walls | Repeating 3-block bands: sulfur, sulfur, tuff, sulfur, potent sulfur, sulfur, tuff |
| Floor (1 block deep) | Sulfur |
| Ceiling | Sulfur |

## Decorations
| Decoration | On | Chance per block |
|---|---|---|
| Sulfur spike | Floor | 4% |

Minecraft's own sulfur cave features also generate: sulfur springs, sulfur pools and sulfur spike clusters, plus geodes, dungeons and springs. **Minecraft's ore generation is removed:** ores come only from the normal [ore system](../ores.md).

## Mobs
Minecraft's own sulfur caves list:

| Mob | Weight |
|---|---|
| Sulfur Cube | 100 |
| Creeper, Skeleton, Zombie | 50 each |
| Slime | 25 |
| Cave Spider | 20 |
| Enderman | 10 |
| Zombie Villager | 5 |
| Witch | 1 |

Hostile mobs get a [level](../../mobs/levels.md) and can be [swapped for tougher mobs](../../mobs/spawn-mix.md). Below Y -1400, swaps can also bring [deep mobs](../../mobs/spawn-mix.md#deep-mobs).
