# Lush Caves

`minecraft:lush_caves` · Y **-40 to -500** · patches about 260 blocks across · about **1.7%** of the world

Minecraft's lush caves biome, with extra moss so it stands out in DwellerMC's huge caves.

## Blocks
| Where | Block |
|---|---|
| Walls | Unchanged (stone or deepslate) |
| Floor (1 block deep) | Moss block |
| Ceiling | Moss block |

## Decorations
Each moss floor or ceiling block tries these in order and stops at the first success:

| Decoration | On | Chance |
|---|---|---|
| Moss carpet | Floor | 10% |
| Short grass | Floor | 8% |
| Azalea | Floor | 1.2% |
| Flowering azalea | Floor | 0.8% |
| Cave vines with glow berries | Ceiling | 3% |
| Spore blossom | Ceiling | 0.3% |

Minecraft's own lush cave features also generate: cave vines, clay pools, azalea trees, vegetation, plus geodes, dungeons and springs. **Minecraft's ore generation is removed:** ores come only from the normal [ore system](../ores.md).
