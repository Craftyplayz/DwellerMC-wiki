# NPCs

NPCs are characters placed by staff. They look like players or mobs and stand around or walk set paths.

## Using them

- Right-click an NPC to talk to it. Some run commands, give you things or open a shop.

## Tips

- If a speech bubble or chat line shows `[Name]:`, it came from an NPC.
- Staff create NPCs. Ask in Discord if you need one.

See also [Disguises](disguises.md) and the [Tab list](tab-list.md).
