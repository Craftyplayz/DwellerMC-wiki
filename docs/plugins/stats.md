# Stats (Plan)

The server records play statistics: how long you play, when you join, kills and deaths. You can see your own in game.

## Commands

| Command | What it does |
|---|---|
| `/plan inspect` | Gives you a link to your stats page. |
| `/plan qinspect` | Short summary of your stats in chat. |
| `/plan ingame` | Your stats in chat. |
| `/plan register` | Create a login for the stats web page, if the server has it turned on. |
| `/plan json` | Your data as raw text. |

You can only look at your own stats. Staff can see everyone's.

## What is counted

Playtime, sessions, the world you were in, kills, mob kills (all [levelled mobs](../mobs/levels.md) count the same) and deaths. Time with no movement counts as AFK after 3 minutes.

Chat is not recorded. There is no map.
