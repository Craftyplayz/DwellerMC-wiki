# Discord bridge

The server chat is linked to our Discord server. Messages you type in game show up in the Discord chat channel, and messages from that channel show up in game with a blue `[Discord]` tag.

## What shows up on Discord

- Your chat messages.
- When you join, leave or join for the first time.
- Deaths and advancements.
- "Server has started" and "Server has stopped".

Private messages (`/msg`) never go to Discord.

## Commands

| Command | What it does |
|---|---|
| `/discord` | Shows the invite link. |
| `/discord link` | Gives you a 4 digit code. Send that code to the server bot in a Discord DM to link your Minecraft and Discord accounts. |
| `/discord linked` | Shows which Discord account you are linked to. |

Linking is optional. It lets the bot show your Discord name and roles next to your chat.

## Tips

- In Discord, typing `playerlist` in the chat channel shows who is online.
- Colored text codes from Discord only work for staff roles.
- Deaths to levelled mobs appear in Discord too. See [mob levels](../mobs/levels.md) and [elites](../mobs/elites.md).
- If you do not want your chat sent to Discord, ask staff.
