# Chat reporting

The server blocks Minecraft's chat reporting. Your messages are sent unsigned, so they cannot be reported through the in-game report menu, and you will not see the "chat messages can't be verified" warning.

Rule breakers can still be dealt with by staff. Tell staff on Discord or in game.

## If you cannot chat

Some accounts are blocked from chatting by the game itself (for example in some countries). You can still talk:

| Command | What it does |
|---|---|
| `/chat <message>` or `/c <message>` | Send a normal public message. |
| `/msg <player> <message>` (also `/tell`, `/w`) | Private message. |
| `/r <message>` | Reply to the last private message. |
| `/me <action>` | Action message. |

You get a hint about `/chat` when you join, until you send your first message.

See also [Discord bridge](discord.md).
